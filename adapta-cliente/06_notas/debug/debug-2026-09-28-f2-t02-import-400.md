# Debug F2-T02 — importação V1 retorna 400 (2026-09-28)

## Sintoma reproduzido

No projeto de teste Skip 55154, versão de desenvolvimento 0.0.68 (`7f4c259`), o runner temporário fez login das contas sintéticas Admin, SDR e Corretor com HTTP 200. SDR/Corretor leram `/backend/v1/catalogo/ativo` (200) e receberam 403 nas rotas de importação, promoção, correção, rollback e histórico. A primeira chamada Admin a `POST /backend/v1/catalogo/importar-fixture` para V1 retornou HTTP 400.

Log request do PocketBase: `accepted: cannot be blank; pending: cannot be blank`.

## Resultado e limite do diagnóstico

A falha interrompeu a sequência antes de V1 staged. Idempotência de import, falha parcial, promoção, correção e rollback ainda não foram provados. A mensagem de validação é observada, mas a causa primária ainda não foi isolada: pode surgir no salvamento do snapshot ou numa tentativa secundária de gravar recibo de falha; não há evidência suficiente para escolher uma hipótese.

A listagem REST direta de `catalog_versions` para SDR/Corretor devolveu 200 com zero registros visíveis; as mutações protegidas pelas rotas retornaram 403. Não descrever a listagem como 403.

## Higiene temporária

O hook `test_f2_t02_smoke.js` foi removido do working tree, `F2_T02_SMOKE_TOKEN` excluído e `F2_T02_ENABLE_FAILURE_INJECTION` desligado/excluído. A versão `0.0.68` foi construída antes da remoção do hook; a ausência do token faz o endpoint temporário responder 401 até o próximo build de preview. Projeto não publicado; sem dado real de cliente.

## Próximo passo

Isolar a primeira exceção na transação de importação V1, corrigir somente F2-T02, reconstruir e executar as provas automatizadas. Não liberar teste humano enquanto as provas principais não passarem. F2-T03 não iniciada.

A falha aparecia mascarada pelo recibo secundário com contadores zero obrigatórios.
- Migrations 0028 (`accepted`/`pending` zero válidos em recibos) e 0029 (`active_candidate`/`stale_review` falso válidos) aplicadas no projeto 55154.

- Limpeza verificada: rotas temporárias de debug/smoke retornam 404; secrets `F2_T02_DEBUG_TOKEN` e `F2_T02_ENABLE_FAILURE_INJECTION` removidos. Projeto não publicado.
